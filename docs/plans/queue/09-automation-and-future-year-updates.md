# Plan 09 — Automation and future-year updates

## Goal

Make the project easy to update when OSPI publishes a new final school year.

## Work

- Workflow checks for newly published/finalized S-275 source.
- Do not overwrite historical raw inputs when hashes change; flag revisions.
- Require validation before appending a new year to published results.
- Record source revisions and their impact.
- Provide one documented command/workflow to rebuild all derived outputs.

## Acceptance

Adding a newly finalized year is an auditable data update, not a manual analysis project.
