# Longitudinal findings

The accepted retained-source analysis compares 2013-14 with 2024-25 using immutable S-275 and normalization snapshots.

## Headline findings

- Student FTE declined from 3,083.12 to 2,818.78, about 8.6%.
- Staff FTE increased from 294.471 to 337.367, about 14.6%.
- Staff FTE per 1,000 student FTE increased from 95.51 to 119.69, about 25.3%.
- In constant 2025 dollars, total salary per student increased 57.7% using national CPI-U and 45.6% using Seattle CPI-U.
- Reported employer compensation per student increased 59.7% using national CPI-U and 47.5% using Seattle CPI-U.
- Strict central-administration employer compensation per student increased 29.8% using national CPI-U and 19.9% using Seattle CPI-U.
- Central plus school administration employer compensation per student increased 39.3% using national CPI-U and 28.6% using Seattle CPI-U.

The increase in overall staffing intensity is not primarily a strict central-office FTE story. From 2013-14 to 2024-25, the largest changes in FTE per 1,000 student FTE were teachers (+8.92), other classified (+5.01), other certificated instructional (+3.39), technical/professional support (+3.37), paraeducators/instructional aides (+2.67), principals/APs (+0.94), clerical/office (+0.66), and district/central administration (+0.12). Custodial/maintenance/facilities declined by 0.91.

## Interpretation boundary

These measures describe staffing and personnel compensation. They do not establish whether staffing changes were necessary, effective, or inefficient. Reported employer compensation is S-275 personnel compensation, not total administrative operating expenditure; broader administrative-cost analysis requires expenditure data such as F-196.

## Source and quality caveats

S-275 public data do not provide an assignment code, so exact Duty Title is the classification key. Director/Supervisor remains outside strict administration because the public title does not identify operating function. Zero-FTE reporting changes sharply in 2024-25. Rows where total salary is below base salary are preserved and flagged. The 2019-20 P-223 source uses actual enrollment through March and projected April-June and summer values.

The retained workflow now generates `longitudinal-findings.json` from the normalized outputs and records the exact immutable snapshot tags used. The narrative values above were validated against retained analysis run 37226782112.
